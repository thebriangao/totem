  Every client below opens a totem page in your browser. Check where access is
  going, then enter the password.

  claude.ai
    Settings → Connectors → Add custom connector. Paste the URL.

  Claude Desktop
    Uses the claude.ai connector: add it there once and it shows up here and in
    the mobile app.

  ChatGPT
    Settings → Apps & Connectors → Create. Paste the URL. (Turn on Developer
    mode under Advanced settings first.)

  Claude Code
    claude mcp add --transport http --scope user whoop \
      https://totem-c0ffee.fly.dev/mcp
    In Claude Code: /mcp → whoop → Authenticate

  Cursor
    Add to ~/.cursor/mcp.json:
    {
      "mcpServers": {
        "whoop": {
          "url": "https://totem-c0ffee.fly.dev/mcp"
        }
      }
    }

  Codex
    codex mcp add whoop --url https://totem-c0ffee.fly.dev/mcp
    codex mcp login whoop

  OpenCode
    opencode mcp add whoop --url https://totem-c0ffee.fly.dev/mcp
    opencode mcp auth whoop

  Another client
    Give it the URL. If it can't sign in through a browser, send the server's
    token as a bearer header instead:
    Authorization: Bearer $(totem token)
